**操作入口：** 侧栏 → 工具市场

## 1. 选择工具并查看要求

从上方分类和目录进入工具详情，查看用途、所需环境和配置。标注“待接入”的工具暂不能使用。

## 2. 保存配置，再添加工具

填写并保存该工具的配置，然后点击“添加工具”。前置检查和实际验证通过后才会显示“已添加”；失败时根据提示跳到配置、认证或运行环境页面处理。

## 3. 连接浏览器工具

在浏览器工具详情按指引安装 Chrome 或 Edge 的浏览器扩展，打开希望使用的浏览器和标签页，再添加工具。需要验证码或人工验证时，按接管卡片提示完成后继续。

## 4. 按需添加自定义工具

选择“新增自定义工具”，按服务提供方说明填写连接方式、服务名称、命令与参数或 HTTP 地址。凭据填写环境变量引用。“测试连接”使用当前草稿且不会保存；保存后仍需点击“添加工具”。

## 试着这样说

```text
请使用浏览器读取我指定的公开网页，提取产品名称、版本和主要变化，整理成表格并保留来源链接。
```

## 完成标志

工具显示“已添加 · 可用”，在对话的“工具”入口能够查看它的状态。

> **使用提示**
>
> “移除工具”会停止能力并保留配置，重新添加会再次验证；只有自定义工具额外提供“删除”。必要依赖被其他工具引用时，需要先处理依赖方。
