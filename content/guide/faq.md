## 模型没有回复，或提示认证失败

先在“设置 → 模型”核对当前模型所属服务的密钥，再检查 API 地址和模型名称。连接超时时查看“设置 → 代理”和网络状态，用简单文本问题验证后再重试原任务。

[查看相关操作](/guide#models)

## 工具保存了配置，为什么仍是“已移除”？

保存只更新配置。回到该工具详情点击“添加工具”，等待实际检查通过。“测试连接”也不会改变添加状态；根据失败提示修复后重新添加。

[查看相关操作](/guide#tools)

## 浏览器工具找不到标签页或要求人工接管

核对对应 Chrome / Edge 已安装并启用详情页指定的扩展，打开目标标签页。登录、验证码等操作按照接管卡片完成；不要反复重试同一项验证。

[查看相关操作](/guide#tools)

## 运营 AI 市场提示未认证或登录过期

到工具市场的运营平台认证详情打开认证入口，按指引完成登录，确认可用后返回市场刷新。市场需要的平台认证与模型 API Key 是两项不同配置。

[查看相关操作](/guide#skills)

## 安装了技能，却在对话中看不到

查看安装结果是否存在重名或依赖提醒，确认当前会话使用正确的专家。默认专家若曾解除该项引用，需要重新启用；自定义专家要在编辑页显式引用。部分技能仅由助手自动调用，不出现在手动选择列表。

[查看相关操作](/guide#skills)

## 知识资料已上传，为什么检索不到？

确认传输和解析已结束、质量提醒已检查、索引可用，并且知识库为“已添加”。先使用资料原文中的关键词在库内检索；只有库内检索正常后，再检查专家是否引用该库。

[查看相关操作](/guide#knowledge)

## 扫描 PDF、图片或旧版 Office 文件无法解析

目前没有内置 OCR。扫描文件请先转换为带文字层的资料；旧 DOC / PPT 先另存为 DOCX / PPTX。解析环境缺失时在知识库的存储与解析设置中按指引配置。

[查看相关操作](/guide#knowledge)

## 定时任务到了时间，没有执行

先确认任务未暂停，应用后台在运行且电脑没有睡眠，再检查执行记录。失败记录中可打开会话核对模型、工具、权限或资料路径；修复后按需立即执行一次。

[查看相关操作](/guide#tasks)

## 官网有新版，应用却没有提示

检查设备平台和安装方式，确认是正式安装版还是 Windows ZIP。新版可能按平台或分批开放；可在托盘手动检查，也可阅读官网更新说明。

[查看相关操作](/guide#updates)

## 仍然无法解决，如何反馈？

记录出错时间、操作步骤、应用版本与界面提示，到“设置 → 帮助”导出诊断日志。检查并去除不宜分享的工作内容，再交给维护人员。不要发送 API Key 或登录凭据。

[查看相关操作](/guide#updates)
