**操作入口：** 官网 → 下载桌面版

## 1. 选择与你的电脑匹配的版本

Windows 10 / 11 的 x64 设备选择 EXE 安装包；Mac 的 M 系列芯片设备选择 Apple Silicon DMG。Intel Mac 暂不在当前分发范围内。

## 2. 完成安装并打开

Windows 按安装向导完成安装；macOS 打开 DMG，将应用拖入“应用程序”后打开。Windows 也可选择免安装 ZIP，完整解压后再启动应用。

## 3. 准备模型服务

向你的模型服务提供方或组织管理员取得 API 地址、模型名称及 API Key。已有默认模型时，只需准备对应密钥；下一节说明如何填写。

## 完成标志

应用窗口可以正常打开，能够进入设置和新建对话。

> **使用提示**
>
> 下载区显示“安装包准备中”时，表示该平台尚未提供正式发布包。基础运行环境随应用提供，个别工具或文档解析仍可能需要额外依赖。
