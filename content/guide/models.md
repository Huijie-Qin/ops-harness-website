**操作入口：** 左下角设置 → 模型

## 1. 配置默认模型

找到“默认”分组中的“DeepSeekV4 - 工作助手默认”，打开密钥配置入口，填写并保存自己的 API Key。默认模型的地址、模型名称和上下文参数由产品预置。

## 2. 需要时添加其他模型

添加组织提供的 OpenAI 兼容服务，按提供方说明填写服务标识、API 地址、协议和密钥，再配置该服务下的模型。不要把聊天网页地址当作 API 地址。

## 3. 选择并验证

回到新对话，在输入框旁的模型选择器中选中模型，发送一句简单的问题。正常收到回复后，再开始处理文件或调用工具。

## 试着这样说

```text
请用三句话介绍你能怎样帮助我整理工作资料。
```

## 完成标志

选中的模型可以正常回复，界面不再提示缺少凭据。

> **使用提示**
>
> 鉴权失败时检查密钥与所选服务是否匹配；连接超时先检查网络，企业代理在“设置 → 代理”中配置。密钥不要写进提示词、技能正文或分享截图。
