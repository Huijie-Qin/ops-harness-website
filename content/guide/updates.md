**操作入口：** 设置 → 帮助 → 软件更新，或系统托盘 → 检查更新

## 1. 检查与下载

从桌面托盘打开“检查更新”，阅读版本说明后确认下载。可以稍后处理或跳过当前版本；手动检查可以再次查看跳过的版本。

应用默认接收正式版更新。需要提前体验时，在“设置 → 帮助”的软件更新区开启测试版更新，可接收 Beta / RC 候选版；开启后仍会接收正式版。测试版可能存在尚未解决的问题，下载和安装仍需你确认。

关闭测试版更新只改变后续可接收的版本，不会降级当前应用。已经使用 Beta / RC 的用户会等待更高正式版，例如 `0.3.0-beta.2` 可以升级到 `0.3.0` 正式版。其他预览版本不会由新版应用自动提供，可在官网更新页识别版本类型后手动下载。

## 2. 保存工作，再重启安装

下载完成后，保存当前编辑内容并等待任务结束，再选择“重启并安装”。普通关闭或退出应用不会自动安装已下载的更新。

## 3. 按安装方式处理

Windows EXE 安装版和 macOS Apple Silicon 支持应用内更新；Windows 免安装 ZIP 请从官网下载新版。官网可能先展示新版，应用内升级还会受平台与分批开放策略影响。

## 4. 保留重要资料

应用配置、会话和工作文件独立于安装目录。备份工作空间与知识存储目录；遇到问题，可在“设置 → 帮助”查看数据与日志位置并导出日志。

## 完成标志

更新后重新打开应用，核对版本、工作空间及常用能力。

> **使用提示**
>
> 卸载软件时留意清理数据的选项。导出诊断日志后，分享前检查是否包含工作信息。
