## 真实浏览器

Chrome，生产构建，独立服务 `127.0.0.1:4187`，独立 releaseDirectory / contentDirectory。

1. 登录后，四个区域“帮助文档 / 发布包 / 目录配置 / 图片库”可切换。
2. 系统文件选择器上传项目原始 `tools.jpg`，Vditor 正文插入 `/media/<sha256>.jpg`；图前、图后段落、图片实际解码（1470 × 746）、发布阅读页均正确。
3. 图片库读取上传项，在分屏和所见即所得模式中插入并保留说明；剪贴板 PNG 粘贴通过真实上传流程，有效 PNG 实际解码为 1 × 1。验收时发现损坏图片可混入，已补浏览器解码与 PNG chunk/CRC 校验并回归。
4. 新增“图文教程”分组，将测试章跨组移动、调整分组顺序、保存。阅读页目录、当前分组、前后章导航均按新配置展示。
5. 未保存正文切换区域显示应用内确认框；放弃测试草稿后不会影响已保存版本。
6. 创建隔离测试版本 9.9.9，保存 changelog，系统选择器上传测试 EXE，显示上传状态、文件大小、SHA-512。确认框显示平台、版本、文件和更新说明；确认发布后公开下载可读。
7. 发布后补充 changelog，公开更新页显示最新三条内容。重启服务后，版本、目录、图片、章节均保留。
8. 桌面与 390 × 844 窄屏检查，管理表单及读者页 `scrollWidth === innerWidth`，无横向溢出；已修正表单留白和移动阅读页标题边距。
9. 最终 Console 无 error/warn。生产 CSP 下，编辑器、图标和图片正常加载。原有安装包协议与 CLI 发布测试保持通过。
