| 场景 | 原片内容依据 | 原生呈现 |
| --- | --- | --- |

| 办公协同 | 约 43.3s：今日重点包含 17:00 前提交国庆追剧季材料、18:00 前审核召回 PUSH、14:00 PUSH 策略例会；约 45.7s：一句话安排会议并通知联系人 | `CollaborationScene.vue` 从日程与邮件进入今日重点，再显示“约张三、李四明天上午 10 点开 10 月版本需求评审会，并在 WeLink 上通知他们”的任务与查找联系人、创建会议、通知 2 人已送达的演示结果 |

四章由 `HomeChapters.vue` 编排，生产系统章节可切换数据分析与内容合规两个场景。组件使用真实文本与正式图标重组原片的信息结构，深色面板、层次和过渡服务于首页阅读，不宣称逐像素复刻产品界面。技能获取、专家分发和知识同步分别呈现，不暗示技能会自动打包成专家。

## 展示与交互边界

- 宽屏桌面可随滚动推进三步，也可点击步骤；窄屏、较矮窗口和减少动态效果模式使用手动步骤。减少动态效果模式关闭场景过渡。各场景由外层传入步骤，无内部计时器或自动播放。
- 内部 UI 是场景演示，提供随步骤变化的语义描述，不放置无效安装、发送或执行按钮；不调用实际生产系统、联系人、日程、邮件或消息接口。
- WeLink 的完成状态重现宣传片中的任务结果，并标注“宣传片任务演示”，不表示官网已向联系人发送消息，也不额外推断原产品的确认规则。
- 现有首屏影片入口、视频管理、下载 Release API 与真实下载状态继续保留；本次重组只涉及首页首屏下方的内容场景。
- `public/assets/product/chapters/` 与 `docs/qa/home-chapters/` 继续保留为上一轮静态图文方案的素材和验收历史，不代表本轮原生场景的最终效果或验收结果。
