## 真实浏览器

Chrome 152.0.7977.84，生产构建；独立 loopback 临时端口、临时配置与 `.runtime` 存储。密码仅在进程内生成并通过环境传递，无源码或磁盘密码文件。

1. 登录后新建发布，焦点到“选择描述文件”。未导入前没有手动版本字段或保存入口。
2. 无效 YAML 返回 400，显示明确错误。导入有效 YAML 后自动显示版本、Windows x64、原文件名与预期哈希；标题可编辑，更新说明保持用户填写。
3. 未保存时切换目录管理触发应用内确认框，Escape 取消并保留编辑。
4. 保存后版本和描述文件锁定。上传与原文件大小相同、但改动一个字节的 EXE，实际上传接口返回 409；界面显示校验失败，文件仍待上传，发布按钮禁用。
5. 重传正确文件后显示“校验通过”，预期哈希与描述文件一致；确认按钮启用。
6. 发布确认支持 Escape 关闭并恢复触发按钮焦点；键盘 Enter 可重新打开。在确认框内明确点击“确认发布”后，公开列表及下载内容正确。
7. 1440 像素桌面与 390 × 844 窄屏均无横向溢出；减少动态效果模式通过。已查看导入、校验成功与手机截图。
8. 图片库、目录管理、文档编辑、发布包及公开更新页切换正常，重新进入可读已保存发布。
9. 无 pageerror、无服务端异常；网络与 Console 仅有刻意触发的无效描述文件 400、损坏包 409，正常请求没有异常。

验收只上传小型不可执行测试字节，不运行 EXE，也不宣称完成 Windows 目标平台安装升级测试。测试进程、临时配置与全部测试安装包/内容已清理，不向正式发布目录写入数据。
