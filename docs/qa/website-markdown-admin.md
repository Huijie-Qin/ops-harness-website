# 官网交互动效与 Markdown 管理验收

> 迁移前的历史验收记录，原命令与路径仅用于追溯；当前操作见 [官网 README](../../README.md)。

日期：2026-09-13。环境：macOS、Chrome；官网开发服务 `127.0.0.1:4173`，独立管理员验收服务 `127.0.0.1:4187`（先开发，后生产构建）。

## 范围与实现

- 观察 DeepSeek Harness 官网鼠标交互后，为首页增加跟随柔光、扩散轨迹、粒子视差与避让；保留暂停、减少动态效果、可见性与后台控制。
- 官网品牌文案移除 Harness 及“基于 DeepSeek Harness 构建”等表述；真实项目截图保持原图，模型配置中的实际产品名不变。
- 旧指南迁移为 11 个独立 Markdown 章节（包含 FAQ），带 frontmatter、全文搜索、分组目录、前后章导航和代码复制。
- 引入 Vditor 4.0.0，支持管理员登录、三种编辑模式、预览、发布、并发冲突提示、Markdown 下载、历史恢复、回收站。选型记录见 ADR 0012，部署和人工维护见 `docs/runbooks/website-guide-maintenance.md`。

## 真实浏览器验收

- 首页鼠标移动带动柔光、涟漪与粒子；暂停后按钮切换为播放，恢复后继续动画。官网 DOM 文案已清理相关品牌从属表述。
- 在独立内容目录中新建验收章节，编辑中文、表格、粗体与代码块，保存并确认成功反馈；阅读页显示发布内容，复制示例反馈成功。
- 再次修改并保存，查看历史、确认恢复第一版；重启为生产服务后重新登录，恢复后的内容仍存在。
- 未保存草稿切换章节弹出应用确认框，默认聚焦取消；Escape 关闭并保留草稿。移入回收站后阅读页提示章节不存在，恢复后重新加载即可阅读。
- 生产 Vditor 分屏、即时渲染、所见即所得均正常；快捷键保存后可继续编辑，切换章节不重复销毁重建编辑器。
- 桌面 1470 px、手机 390 px 阅读与编辑页面均无横向溢出。手机正文使用单栏，工具栏换行；章节定位在固定导航下方。实际检查搜索“浏览器”返回相关章节，选择结果清空搜索，`#step-2` 兼容跳至模型章节；键盘“跳到正文”不误加载不存在的章节。
- 修复验收发现的默认代码主题 404 和生产图标内联执行被 CSP 阻止的问题：补齐本地资源，单独许可固定图标脚本哈希；没有放开任意脚本内联或 eval。修复后页面正常、图标可见、Console 无 warn/error，最终生产服务日志无请求错误。
- 退出后回到登录页。默认 `4173` 服务没有管理员密码，页面明确提示配置，公开阅读仍提供 11 章内容。
