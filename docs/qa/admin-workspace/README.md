# 管理工作区验收

## 文档编辑与管理拆分后的验收

2026-09-14，依据 ADR 0016 在隔离源码副本与运行目录中验收生产构建。

- `pnpm check`（类型检查与 36 项测试）、`pnpm build` 均通过。
- 编辑页只提供正文编辑、选择文档、预览、下载与历史正文恢复；管理页不加载正文编辑器，目录/文档操作直接显示在分组列表中。
- 实测新建目录、指定目录创建文档并进入编辑页、保存正文、修改名称与简介、跨目录移动、文档上移、目录改名与上移、隐藏/显示、回收与恢复均正常。
- 历史恢复验证：旧正文恢复后，管理页修改的新名称、简介与目录位置保持不变。
- 未保存正文切换管理页会提示；Escape 取消后草稿保留。新建对话框可由 Enter 打开，Escape 返回触发按钮；回收和恢复后焦点回到管理页搜索框。搜索输入与键盘清空可恢复完整列表。
- 1280 像素桌面和 390 × 844 窄屏检查通过，两页没有横向溢出；管理操作不会浮在编辑器上方。减少动态效果规则保留。
- 最终构建实测文档编辑、目录管理、发布包、图片库切换、源码同步清单预览、退出认证及公开阅读正常；公开文档显示新名称、简介、正文与移动后的前后章顺序。
- Console 无错误或警告。最终构建的 42 条页面、资源和业务请求均为 HTTP 200；认证前只有页面资源与会话检查，编辑器在登录后加载。
- 验收后关闭临时页面、停止两项隔离服务并清理源码副本及运行目录；真实官网内容未用于写入测试。

## 原合页方案的历史验收

日期：2026-09-14。Node.js 24.16.0 / pnpm 11.19.0，macOS 本地生产构建，浏览器使用隔离的内容与发布目录。

- `pnpm check`：类型检查与 36 项测试全部通过。
- `pnpm build`：通过，构建复制文档、目录配置及 `content/media`。
- 登录：错误密码被拒绝；认证前仅加载登录页和会话检查，不请求管理文档或编辑器资源；认证后进入管理工作区，退出后回到密码表单。
- 目录树：新建目录、目录改名、新建指定目录下的文档、文档改名、跨目录移动、目录及文档上下排序均通过；公开目录与前后章顺序同步更新。
- 编辑与图片：编辑 Markdown、上传真实 JPEG、保存、公开页显示均通过，图片实际解码宽度为 1470 像素。
- 源码同步：未保存文档先保存，再显示待写入清单；确认后文档、目录、图片和图片索引 4 个文件写入隔离的 content；自动化测试另验证覆盖备份、幂等、修改冲突、恶意路径、损坏图片，以及从同步结果构建后的全新运行目录回读。
- 可访问性：方向键与 Enter 选择文档、Shift + F10 打开菜单、Escape 返回触发位置通过；1280 像素桌面与 390 像素窄屏检查通过，窄屏无横向溢出。管理区不新增动效，并提供减少动态效果的样式规则。
- 页面切换：文档、发布包、图片库、公开指南前后章切换正常。Console 无错误或警告；网络中仅故意输错密码产生预期的 401，其余观察到的业务与资源请求成功。
- 安全回归：伪造转发头不能绕过限流，登录请求体大小与慢速接收有界，并行登录受限；成功登录不能清空全局尝试预算；旧会话轮换和空闲过期有效；同步要求会话、同源与 CSRF，并校验在线/源码 revision。

验收结束后关闭临时浏览器标签页、停止隔离服务并清理临时目录。真实官网的文档、图片和发布数据未用于写入测试。
