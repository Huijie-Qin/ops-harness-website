# 0025 — 官网视频内容库与首页影片播放

- 状态：已接受
- 日期：2026-10-11

## 背景

首页“观看影片”需要播放管理员上传的真实宣传片，并支持产品介绍、功能演示、实践案例分类。视频与官网文档、图片一样属于独立官网的可变内容，不依赖产品 Runtime，也不进入源码或部署镜像。

## 决策

共享契约位于 `shared/videos.ts`。视频目录保存于 `contentDirectory/videos/catalog.json`，条目包含标题、描述、分类、草稿/已发布状态、首页精选标记、封面、秒数、时间戳及可选文件信息。封面为空时使用页面默认封面；非空仅接受 `/media/<sha256>.(png|jpg|webp)` 或受控 `/assets/product/` 图片 URL，拒绝远程 URL、查询串和路径穿越。首页精选最多一条且必须已发布；发布新的精选会在同次目录提交中清除原精选。

管理操作沿用既有 `/api/admin` 登录、会话、同源检查、CSRF 和内容错误码。只读 GET/HEAD 需要有效会话，写入还必须携带 CSRF。所有目录修改携带当前 `revision`，以独占文件锁串行提交并再次验证版本；同目录临时文件、同步和原子 rename 完成持久化。修改前保留旧目录到 `.trash`；删除另保存完整条目快照，因此是软删除。

- `GET /api/videos`：仅返回已发布条目，不返回后台 revision。
- `GET/POST /api/admin/videos`：读目录、创建条目，创建体为 `{ entry, revision }`。
- `PUT/DELETE /api/admin/videos/:id`：保存或软删除，写入体包含 revision，保存另带 entry。
- `POST /api/admin/videos/:id/file?name=<filename.mp4>`：原始 `application/octet-stream` 上传，携带 `X-Revision`；可选 `X-Video-Duration` 将浏览器读取的有限正秒数与文件原子保存。所有变更返回完整目录。
- `GET/HEAD /api/admin/videos/:id/preview`：鉴权播放草稿或已发布视频。
- `GET/HEAD /videos/<sha256>.mp4`：仅在当前目录仍有已发布条目引用时公开读取，支持单段 Range（206/416）。撤回发布后新请求立即不可用；返回 `Cache-Control: no-store`，避免公开缓存继续分发已撤回影片。

上传上限 512 MiB，复用既有流式上传的并发、总时长、空闲超时及临时文件清理。文件在磁盘分块接收和计算 SHA-256，不能一次读入内存。服务端有界检查 ISO BMFF `ftyp`、box 边界、`moov`/`mdat`、视频轨道及 sample description，拒绝伪装、截断、无视频轨道或加密内容。该检查**不解码、不转码、不保证浏览器支持所有编码**；浏览器读取元数据，管理员预览确认可播放。秒数须有限且在 0–86400 内，草稿允许 0，发布必须大于 0 并已有有效文件。替换文件前必须先撤回为草稿。

文件以 SHA-256 命名存入 `videos/files/`，同内容去重。发布前及复用已有文件时流式复核 SHA-256 与大小，避免同大小的磁盘损坏绕过验证。删除条目、替换文件保留历史内容文件，以便依据 `.trash` 快照恢复且不误删其他条目共用的文件。未被任何已发布条目引用的历史文件和上传临时文件无法经公开路由访问。当前没有自动清理历史文件的任务；运维备份须覆盖整个 videos 目录，空间回收必须先核对当前目录与保留的回收记录。

## 验证与限制

HTTP 回归覆盖鉴权、CSRF、草稿隔离、精选唯一、发布/撤回、版本冲突、实际文件字节与 Range/HEAD、软删除、无效/过大/中断上传和临时文件清理。MP4 结构校验另覆盖伪造品牌、越界 box、坏 sample table。生产反向代理须允许 512 MiB 请求体及大文件上传时长，且不能绕过应用直接公开 videos 存储目录。线上内容备份与恢复沿用官网可变内容运维流程。
