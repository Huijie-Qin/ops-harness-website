# ADR 0020：后台 Hash 导航与运营统计界面

状态：已接受。2026-09-21 用户选择第一版设计，并要求刷新后保留当前页面。

后台采用独立的左侧导航，公开官网的顶栏与页脚不出现在后台。文档编辑、目录与文档管理仍为两个页面。运营统计的八个子页在侧栏展开，共用日期、环境与版本筛选；窄屏使用可关闭的导航抽屉。

使用 `/admin#<section>` 保存当前管理页面，文档使用 `#guides/<documentId>`，统计使用 `#analytics/<view>?<query>`。统计查询状态包括日期、环境、版本、搜索、排序、页码、每页条数和所选用户。刷新、登录后和浏览器前进后退均按 Hash 恢复；未知路径和无效参数回退到有效值。Hash 只是界面状态，API 继续独立检查登录和查询参数。未保存编辑仍经应用内确认框保护，密码和会话凭据不进入 URL。

用户明细支持姓名/工号搜索及服务端排序，在分页前执行；查询值参数化绑定，排序字段和方向使用白名单。活跃排名继续采用既有固定规则，不允许自定义排序。核心统计指标不受列表搜索影响，界面明确标注两者范围。

统计表格按身份、活跃情况、用量等分组，固定表头与身份列，数字右对齐并使用千位分隔。列显示偏好保存在当前浏览器，不改变数据口径。日期、Token、匿名记录和拒收原因的解释保持可见；历史累计拒收表不冒充所选日期的结果。

不变更事件协议、数据库 schema、依赖或身份归属规则。人数和数据来自管理 API；设计图中的示例数据只用于隔离目录的界面验收，不写入部署数据。
