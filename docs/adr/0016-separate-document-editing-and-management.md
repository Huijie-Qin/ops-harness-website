# ADR 0016：拆分文档编辑与目录管理

- 状态：接受。2026-09-14 用户反馈两级树菜单遮挡正文，要求恢复两个独立页面。
- 替代 ADR 0015 的合页与树形操作决策，保留两级目录、`/admin` 认证、源码同步、图片库和发布包功能。

“文档编辑”页采用简单文档列表选择器，工作区只提供 Markdown 正文编辑、预览、下载与历史正文恢复，不提供名称、简介、目录、排序、新建或回收操作。历史恢复通过现有带 revision 的章节保存接口只替换正文，保留当前元信息；切换文档或管理功能时继续保护未保存草稿。

“目录与文档管理”页用完整宽度的分组列表展示目录和文档，按钮直接显示，不使用树节点与浮层菜单。目录可新建、改名、排序和删除空目录；文档可新建、修改名称与简介、跨目录移动、排序、隐藏、回收和恢复。新文档使用稳定目录 ID 与目录 revision 创建，保存初始正文后进入编辑页。所有写操作复用既有鉴权、CSRF 和并发检查，保存只写运行目录。

表单与确认沿用应用内对话框，支持键盘、Escape 和焦点恢复；窄屏下目录标题、文档说明和操作按钮纵向排列。浏览器验收使用隔离源码副本、运行目录和测试凭据，不修改真实文档。完成类型检查、测试、构建，并验证页面边界、草稿保护、历史正文恢复、文档管理、窄屏和公开阅读。
