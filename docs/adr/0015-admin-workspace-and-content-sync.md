# ADR 0015：统一文档工作区、管理员认证与源码同步

- 状态：接受，2026-09-14 用户要求合并文档和目录管理、使用 `/admin`，并将后台修改连同图片同步到 `content`；用户确认只保留“目录 → 文档”两级结构。
- 文档与目录合页的 UI 决策已由 [ADR 0016](0016-separate-document-editing-and-management.md) 替代；本 ADR 的鉴权和源码同步决策继续有效。
- 补充 ADR 0012、0013、0014。日常发布仍写入运行目录，仅显式同步操作可以写回源码。

管理员入口为 `/admin`，旧 `/guide/admin` 及 `/admin/` 重定向到该地址。入口先检查会话，未认证仅显示密码表单；编辑器、发布包和图片库在认证后按需加载。所有管理 API 都在服务端校验会话，写操作继续检查 Host、Origin 和 CSRF。管理入口和 API 禁止缓存，入口禁止索引；生产管理员页沿用锁定编辑器图标脚本的 CSP 哈希。

密码只从环境读取，在启动时用随机盐派生 scrypt 哈希，登录比较使用常量时间比较。每个实际连接地址 5 分钟最多 5 次尝试，全站每 5 分钟最多 50 次，限制在读取请求体之前计数。最多 2 个登录请求同时接收并执行密码派生；登录 JSON 上限 2 KiB、接收超时 5 秒，拒绝压缩请求。限流返回 429 和 Retry-After，伪造转发头不改变身份。会话使用随机令牌，服务端只存令牌摘要，Cookie 带 HttpOnly、SameSite=Strict、HTTPS 时带 Secure；再次登录轮换旧会话，8 小时绝对过期，30 分钟闲置过期。密码长度规则保持不变。这些应用限制不能代替公网网关的连接数、请求速率和 TLS 策略；应用不信任客户端自行提供的代理地址。

“文档与目录”页左侧为两级树，目录与文档均可通过菜单改名、调整顺序；目录可新建文档，文档可跨目录移动。移动与排序即时保存，使用目录 revision 防止并发覆盖。新建文档同时提交目标目录的稳定 ID 和 revision，避免同名目录造成归属错误；目录写入失败则撤销本次新文档。右侧沿用 Markdown 编辑、预览、历史、回收站和未保存提醒。树与菜单提供方向键、Home / End、Enter、Escape、焦点恢复和窄屏布局。

新增 GET/POST `/api/admin/content-sync`。GET 返回待新增/覆盖的固定相对文件清单及覆盖在线内容和目标文件哈希的 revision；POST 校验同一 revision 后写入，客户端不能指定目标路径。目标固定为官网工作目录的 `content`，只包括在线 Markdown、目录配置及图片和索引，不改动其他内容、不清除运行覆盖、不执行 Git 操作。同步前如有当前文档草稿，界面先保存，再展示同步清单并确认。

同步按文档锁、图片锁、同步锁的顺序串行执行；校验文件类型、大小、图片哈希与尺寸、目标文件和目录的符号链接边界。先将新旧文件及清单备份到运行目录的 `sync-backups/<id>`，再逐文件以同目录临时文件加 rename 替换。发生错误时仅在目标仍是本次写入版本时回滚，避免覆盖随后发生的人工编辑。进程中断或回滚不完整时保留 `content-sync-review.json`、备份和未完成锁，后续同步停止，需维护人员核对；不宣称跨文件的文件系统事务。

`content/guide/navigation.json` 提供基础目录配置，运行目录中的配置优先；`content/media/index.json` 和内容哈希命名的图片提供基础图片库，运行图片优先，仅缺失时读取基础图片。构建同时携带目录与图片，所以提交后的源码在新环境中能独立恢复阅读顺序和图文内容。验证覆盖恶意登录、会话、CSRF、路径边界、并发冲突、备份、源码同步及构建后的图片回读；UI 验收使用隔离的内容及发布目录。
